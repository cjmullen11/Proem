# Proem

**Status:** In Development  
**Technologies:** HTML · CSS · JavaScript

## Overview

Proem is a lightweight personal portfolio website presenting my background, curriculum vitae, and technical projects. I am building it to keep my professional information accessible while practicing straightforward, maintainable web development.

The name **Proem** comes from the Greek *prooimion*, meaning an introduction or preface—a fitting description of the website's purpose.

## Key Design Choices

- **Minimal stack:** Use semantic HTML and shared CSS without a heavy frontend framework.
- **Consistent entries:** Reuse layouts for experience and project descriptions while keeping page-specific styles separate.
- **Clear project navigation:** Present short project summaries, development status, and links to further documentation.
- **Responsive design:** Favor readable typography and layouts that work across screen sizes.
